AquaFlow Phase 4 / Timeline Editing Patch
========================================

Patch purpose
-------------
This patch adds the next practical operator-facing phase after server-authority and persistence:
1. Interactive timeline clip editing
2. Track mute / solo control
3. Clip selection with Inspector-side clip editing
4. Keyboard clip delete / duplicate helpers
5. Backend runtime playback honoring muted / solo tracks

Apply on top of
---------------
- Phase 1 stabilization build
- Phase 2 interaction hotfix
- Phase 3 server-authority / persistence patch

Files included
--------------
backend/engine/show_engine.py
frontend/src/components/panels/InspectorPanel.jsx
frontend/src/components/timeline/Timeline.jsx
frontend/src/store/showStore.js
PHASE4_INSTALL.txt
PHASE4_PATCH_SCOPE.txt

Windows install steps
---------------------
1. Stop AquaFlow backend and frontend windows.
2. Back up your current AquaFlow folder.
3. Extract this patch ZIP.
4. Copy the included files into your AquaFlow project root and allow overwrite.
5. Open Command Prompt in the AquaFlow project root.
6. Run:
   npm --prefix frontend install
7. Start the platform:
   start-all.cmd
   - or if needed:
     start-backend.cmd
     start-frontend.cmd

Quick verification
------------------
1. Open the app and click a timeline track.
2. Double-click inside a timeline row to create a clip.
3. Drag a clip left/right to move it.
4. Drag clip edges to resize it.
5. Click a clip and confirm the Inspector now shows clip properties.
6. Edit label, start, end, or intensity from the Inspector.
7. Use Duplicate and Delete from toolbar or Inspector.
8. Toggle Mute and Solo on tracks and confirm the visual state changes.
9. Run playback and verify muted tracks are ignored; if any track is soloed, only soloed tracks should be active.
