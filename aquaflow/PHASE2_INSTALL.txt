AquaFlow Studio – Phase 2 Interaction Hotfix

Purpose
This patch activates UI controls that previously looked clickable but produced little or no visible response.

What this patch updates
- frontend/src/components/TopBar.jsx
- frontend/src/components/nodes/NodeEditor.jsx
- frontend/src/components/panels/DevicePanel.jsx
- frontend/src/components/panels/DeviceDiscoveryPanel.jsx
- frontend/src/components/panels/InspectorPanel.jsx
- frontend/src/store/showStore.js

Installation steps (Windows)
1. Close any running AquaFlow frontend/backend command windows.
2. Back up your current AquaFlow folder.
3. Extract this patch ZIP directly into your existing AquaFlow project root.
4. Allow Windows to replace the existing files.
5. Open Command Prompt in the AquaFlow project root.
6. If frontend dependencies were already installed before, you can usually skip reinstall. If unsure, run:
   npm --prefix frontend install
7. Start the system again:
   start-all.cmd
   or run separately:
   start-backend.cmd
   start-frontend.cmd

Verification checklist
1. Top menus now trigger actions (Add Track, Add Node, Quantize, Scan Network, Toggle Grid/Snap).
2. Transport buttons update local UI immediately and still send backend commands.
3. Node Editor toolbar buttons switch modes and + Add Node inserts a node.
4. In Connect mode, click an output port and then an input port to create a connection.
5. Device panel Scan Network button performs a real quick scan request.
6. Inspector device actions now send Test / Identify / Emergency Stop requests.
7. Inspector AI tab can request a generated pattern and apply it to a track.
8. Device Discovery scan no longer silently falls back to fake demo results unless explicitly enabled with VITE_ENABLE_DEMO_SCAN=true in development.

Notes
- This patch is intended to be applied on top of the previous Phase 1 stabilization build.
- If the frontend does not reflect the new behavior, stop the dev server and start it again.
- If something goes wrong, restore your backup and reinstall the previous patch.
