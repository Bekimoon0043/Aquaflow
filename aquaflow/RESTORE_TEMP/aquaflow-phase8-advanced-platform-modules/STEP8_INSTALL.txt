Install instructions for AquaFlow Step 8 package

1. Stop AquaFlow frontend and backend if they are running.
2. Extract aquaflow-phase8-advanced-platform-modules.zip to a temporary folder.
3. Copy the extracted contents into the AquaFlow project root, preserving folders.

Windows example:
cd /d "%USERPROFILE%\Downloads\aquaflow-phase1-stabilization-clean\aquaflow"
xcopy /E /Y /I "%USERPROFILE%\Downloads\aquaflow-phase8-advanced-platform-modules\*" "."

4. Install frontend dependencies:
npm --prefix frontend install

5. Install backend dependencies:
py -m pip install -r backend\requirements.txt

6. Start the frontend:
npm --prefix frontend run dev

7. Start the backend:
cd /d "%USERPROFILE%\Downloads\aquaflow-phase1-stabilization-clean\aquaflow\backend"
py -m uvicorn main:app --reload --host 0.0.0.0 --port 8000

8. Verify in browser:
- Frontend: http://localhost:3000
- Backend health: http://localhost:8000/api/health
- AI moods: http://localhost:8000/api/ai/moods
- Audio capabilities: http://localhost:8000/api/audio/capabilities

9. Verify Step 8 UI:
- Top bar shows 3D, AI, Devices, Audio, PLC, and Schedule panels.
- 3D panel renders preview scene.
- AI panel can generate or pattern-fill tracks.
- Audio panel can upload, analyze, and sync music.
- Devices panel can scan/test/configure hardware.
- Show Browser can create/open/save shows.
