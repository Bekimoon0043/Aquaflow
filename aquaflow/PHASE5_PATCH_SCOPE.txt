Phase 5 Patch Scope
===================

Primary objective
-----------------
Add editor history controls so operators can safely experiment with timeline and node edits, then undo or redo changes without reloading the show.

Implemented changes
-------------------

1. Global undo / redo history
- Added bounded editor history stacks for show-authoring state.
- Undo / redo now restores show data, nodes, connections, devices, timeline tracks, and selection state.
- History resets cleanly when authoritative server snapshots or file loads replace the local document.

2. Timeline history integration
- Timeline toolbar now includes Undo and Redo buttons.
- Keyboard shortcuts now support:
  - Ctrl/Cmd + Z for undo
  - Ctrl/Cmd + Y for redo
  - Ctrl/Cmd + Shift + Z for redo
- Clip move and resize drag operations are grouped into one undo step instead of flooding the history stack.

3. Node editor history integration
- Node dragging now records as a single undoable movement transaction.
- Node placement and connection edits participate in editor history.

4. Menu / operator workflow improvements
- Top bar Edit menu items Undo and Redo are now wired to real actions.
- Top bar quick buttons for Undo and Redo were added next to Open / Save.
- Status bar now exposes current undo and redo depth.

5. Data safety behavior
- History is capped to a fixed depth to prevent runaway memory growth.
- Temporary drag transactions are cancelled if the operator clicks without actually moving the object.

Not included yet
----------------
- Multi-select timeline editing
- Marquee selection
- Clip overlap conflict resolution / auto-healing
- Track reorder UI
- Automated regression tests
