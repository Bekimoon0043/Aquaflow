Phase 4 Patch Scope
===================

Primary objective
-----------------
Add real editing capability to the timeline so AquaFlow operators can create, modify, duplicate, delete, inspect, mute, and solo cues directly in the UI while preserving backend-authoritative runtime behavior.

Implemented changes
-------------------

1. Timeline editor interaction
- Timeline clips can now be created directly on tracks.
- Double-click on a track row inserts a clip at the clicked time.
- Toolbar now supports:
  - add track
  - add clip
  - duplicate selected clip
  - delete selected clip
  - quantize
  - AI generate
- Selected clip details are shown in the timeline footer.

2. Direct clip manipulation
- Clip body drag moves the clip.
- Left and right edge drag resizes clip boundaries.
- Snap-to-grid is respected when enabled.
- Clip duration and show duration are normalized automatically.

3. Global clip / track selection state
- Store now tracks:
  - selectedTrackId
  - selectedClipId
- Selecting nodes or devices clears clip selection.
- Selecting clips clears node/device selection.

4. Inspector clip editing
- Inspector now detects clip-only selection mode.
- Clip inspector supports editing:
  - label
  - start
  - end
  - intensity
- Clip inspector supports duplicate and delete actions.
- Timeline clip selection is now a first-class editing workflow.

5. Track control state
- Timeline tracks now support:
  - muted
  - solo
- Track header controls toggle mute and solo.
- New tracks and backend-loaded tracks are normalized to include these flags.

6. Backend runtime behavior
- Show engine playback evaluation now ignores muted tracks.
- If one or more tracks are soloed, playback only evaluates soloed tracks.
- Runtime commands now carry clip label metadata for richer downstream handling.

7. Store / data model improvements
- Added timeline clip CRUD actions:
  - createTimelineClip
  - updateTimelineClip
  - removeTimelineClip
  - duplicateTimelineClip
- Added track selection / control actions:
  - selectTrack
  - selectClip
  - toggleTrackMute
  - toggleTrackSolo
- Snapshot and load paths normalize track/clip structure for consistency.

Not included yet
----------------
- Full undo / redo stack
- Clip overlap conflict resolution
- Multi-select editing
- Marquee selection
- Drag-copy with modifier keys
- Track reorder UI
- Automated regression tests
