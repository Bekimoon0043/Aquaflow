Install instructions for AquaFlow Step 7 package

1. Stop the AquaFlow frontend and backend windows if they are running.
2. Extract the Step 7 ZIP into a temporary folder.
3. Copy the extracted contents into the AquaFlow project root and overwrite existing files.

Windows example:
cd /d "%USERPROFILE%\Downloadsquaflow-phase1-stabilization-cleanquaflow"
xcopy /E /Y /I "%USERPROFILE%\Downloadsquaflow-phase7-hardening-and-qa\*" "."

4. Run install.cmd to refresh dependencies, create frontend\.env.local if missing, and verify backend syntax.
5. Start with start-all.cmd, or run start-backend.cmd and start-frontend.cmd separately.
6. If Vite says port 3000 is busy, use the alternate localhost URL it prints, such as http://localhost:3001.
7. Verify:
- http://localhost:8000/api/health
- http://localhost:8000/api/ai/moods
- http://localhost:8000/api/audio/capabilities
- frontend app loads and connects without the stale-backend banner on the active Vite port
