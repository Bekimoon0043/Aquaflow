Phase 6 Install
===============

1. Extract the phase 6 patch into a temporary folder.
2. Copy the patch files into the AquaFlow project root, allowing overwrite.
3. Run: npm --prefix frontend install
4. Restart both servers:
   - frontend: npm --prefix frontend run dev
   - backend:  py -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
5. Verify:
   - Ctrl/Cmd-click selects multiple clips
   - Shift-drag on empty timeline creates a marquee selection
   - Duplicate/Delete affects all selected clips
   - Track headers reorder tracks with up/down arrows
   - Heal removes timeline clip overlaps by pushing collisions forward
