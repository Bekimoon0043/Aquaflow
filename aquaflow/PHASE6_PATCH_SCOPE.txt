Phase 6 Patch Scope
===================

Primary objective
-----------------
Upgrade the timeline editor from single-item editing to advanced sequencing workflows with clip multi-select, marquee selection, bulk actions, conflict healing, and track reordering.

Implemented changes
-------------------

1. Multi-select timeline clips
- Timeline selection now supports multiple clips at once.
- Ctrl/Cmd-click toggles clips into or out of the current selection.
- Selection state is preserved through undo / redo.

2. Marquee selection
- Shift-drag on empty timeline space creates a marquee box.
- Clips intersecting the marquee become selected.
- Ctrl/Cmd + Shift-drag adds the marquee result to the existing selection.

3. Bulk timeline actions
- Duplicate and Delete now operate on the whole clip selection when multiple clips are selected.
- Keyboard shortcuts continue to work for bulk operations.

4. Track reorder UI
- Track headers now include up/down controls to reorder tracks directly in the timeline.
- Reordering is undoable.

5. Overlap conflict handling
- Clip create, move, resize, duplicate, quantize, AI pattern apply, and manual healing now pass through overlap healing.
- Overlapping clips on the same track are automatically pushed forward to preserve order instead of silently colliding.
- A Heal button in the timeline can normalize a track layout on demand.

6. UX feedback improvements
- Timeline footer now reports multi-selection counts and marquee hints.
- Track headers show order index and clip counts.

Not included yet
----------------
- Cross-track clip grouping
- Clipboard copy / paste for clips
- Timeline lane folders / collapsing
- Automated regression tests
- Collaborative multi-user conflict resolution
